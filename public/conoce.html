ANTES DE EMPEZAR

Respuestas claras.

¿Necesitas revisar tu grupo?
Abre el bot y utiliza /estado.

¿Tengo que dejar mi computador encendido?

No. GBot funciona en un servidor externo. Puedes cerrar el panel y seguir usando Telegram.

¿Puedo usarlo en varios grupos?

Sí. El panel muestra los grupos que puedes administrar. Cada grupo conserva sus propios ajustes y suscripción.

¿Por qué necesita ser administrador?

Telegram exige permisos concretos para borrar, silenciar, restringir ingresos o gestionar temas. El bot solo puede ejecutar las acciones para las que tenga permisos.

¿Puedo probar el panel antes?

Sí. La demostración pública usa datos de ejemplo. No modifica grupos reales ni procesa pagos.

¿Las sanciones de una Alianza son automáticas?

Cada grupo revisa y decide qué casos aplica. Compartir un perfil también requiere revisar los cambios antes de adoptarlo.

¿Qué información utiliza GBot?

Para administrar un grupo, el servicio registra identificadores de Telegram, configuración, actividad y acciones de moderación. La protección antispam consulta el identificador numérico del usuario a CAS (cas.chat), un servicio externo. Se cachea el resultado para reducir consultas y no se envía el contenido del mensaje a CAS. El asistente de IA es opcional: al activarlo, las consultas explícitas, las normas públicas y la orientación configurada se envían a Groq. No se envía el historial; GBot conserva respuestas hasta una hora y no guarda preguntas en la base de datos. Las credenciales de bots con marca propia se almacenan cifradas y solo sus administradores pueden gestionar la conexión. El filtro visual es opcional: al activarlo, el administrador autoriza enviar fotos a OpenAI Moderation para detectar posible contenido sexual. GBot no almacena las imágenes; conserva resultados en caché hasta siete días y un historial de hasta treinta días. No analiza vídeos ni identifica edades. El panel requiere autenticación y permisos vigentes. Evita incluir información sensible en mensajes personalizados, notas y motivos de sanción.
